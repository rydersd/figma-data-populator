# Session Notes — Figma Data Populator

## Where Things Stand

- Import/paste
  - CSV/TSV import and drag/drop auto-populate Column Setup under the textarea. No preview pane in‑plugin.
- Header/controls
  - Mode toggle uses text ("Table", "Cards"), vertically aligned with "Configure Columns". Configure opens a centered, animated view with sticky header/footer.
- Column Setup
  - Compact toggles (Text/Symbol, px/fill, Left/Center/Right) + responsive layout to avoid clipping.
  - Width summary bar shows "Fixed px, Fill count, Target px, OK/Scroll risk".
  - Redistribute resets uniform widths (Target / columns). Fit columns converts fill to px and shares remaining width.
- Generate/Apply
  - Column widths are respected: px uses horizontal sizing (`layoutSizingHorizontal='FIXED'` or counter-axis FIXED) then resize; fill uses `layoutGrow=1` and `layoutSizingHorizontal='FILL'` when available.
  - Transparent frames: cells/table frames default to transparent fills; only header/zebra apply backgrounds.
- Scrollable Body
  - BodyRows Component + Body instance inside BodyScroll (clipped container). Apply updates BodyScroll height.
- Update in place + Apply
  - Works from either table root or any child; we auto-find the table root (Header + Body/BodyScroll). Apply updates widths, alignment, typography.

## Troubleshooting Notes

- If import breaks, check for null references to removed controls (e.g., old `#mode` select, preview handlers). Ensure `updateOptionVisibility()` reads `#modeVal`.
- If px widths don’t stick, confirm horizontal sizing is fixed (`layoutSizingHorizontal='FIXED'` or counter-axis `FIXED`) before resizing; for fill, use `layoutGrow=1` and horizontal `FILL`.
- If Mode doesn’t switch UI, make sure icon toggle sets `#modeVal` and fires `updateOptionVisibility()`.
- Scrollable Body: apply widths by editing the `BodyRows` component (the master) rather than the `Body` instance inside `BodyScroll`.
- After closing Configure, the main view scrolls to the top to avoid extra scrolling.
